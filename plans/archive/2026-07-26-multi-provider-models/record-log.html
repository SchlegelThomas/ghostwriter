Parallel research covered LiteLLM, Portkey, OpenRouter, Helicone, Cloudflare AI Gateway, Vercel AI SDK (+ hosted AI Gateway BYOK), LangChain/LangGraph, Kong, Bifrost, TrueFoundry, LLMWare.

Parent synthesis / recommendation for the plan:

  1. Primary: Direct provider calls via Ghostwriter registry + Vercel AI SDK packages inside packages/ai adapters. Per-request BYOK from decrypted envelopes. Do not require Vercel’s hosted AI Gateway (team-scoped BYOK is the wrong tenancy model).
  2. Hybrid escape hatch: OpenRouter as one optional named provider for long-tail + rich /models metadata. Not the sole upstream. Note workspace BYOK fee after free monthly allowance.
  3. LiteLLM: Strongest OSS OpenAI-compat proxy with clientside key forward, but Python sidecar + hop fights the current Node/Fly shape. Defer unless org-gateway needs appear (D6).
  4. Avoid as core: Portkey (acquisition trajectory), Helicone/Kong/Bifrost/TrueFoundry as the writer BYOK plane, LangChain as the provider layer.
  5. Available models: curated Ghostwriter catalog ∩ providers with valid keys (+ light validate/discovery on save), not live-only noisy lists and not probe-on-every-paint.
