Ghostwriter delivery plan

Public media, demo keys, Reader voice

Status: active
Branch: feat/proactive-next-actions (session; split PR later if needed)
Owner: founder + agent

Intent

Production Cast portraits load without a private download hop; the demo account can use the same BYOK keys as local; Reader voice failures offer a clear configure path. Capture attachments stay private (ADR 0010).

Out of scope: public Capture attachment bytes; client-side ElevenLabs keys; Terraform (Wrangler CLI scripts are enough for v1).

Acceptance criteria

  • Demo Cast portraits resolve to real public HTTPS image URLs and render in prod.
  • Wrangler-scripted provision + sync of public media is documented and runnable.
  • Applied character visuals can store public URLs when GHOSTWRITER_PUBLIC_MEDIA_ORIGIN is set; UI uses them without /download.
  • Prod/demo boot seeds OpenAI/Anthropic/Google keys into demo@ghostwriter.app from GHOSTWRITER_DEMO_SEED_*_KEY Fly secrets (same values as local when configured).
  • Reader “voice not configured” shows a quick link that opens Settings → Reader voice with ops guidance for ELEVENLABS_API_KEY.

Tasks

  1. CP1 — Reader voice quick link: Settings focus + banner CTA; copy for Fly secret.
  2. CP2 — Demo BYOK seed: Mirror hermetic E2E key seed for production demo account.
  3. CP3 — Public media IAC: Wrangler bucket/domain script; sync Harry Potter PNGs; env origin; seed + apply write public URLs; UI skip locator resolve for public hosts.
  4. Docs/ADR note: public character media vs private Capture; OPERATIONS Fly secrets list.

Tests and verification

  • Unit: public URL helper; demo credential seed; Settings focus includes reader-voice.
  • Reader banner renders configure control when voice error is VOICE_UNAVAILABLE.
  • Manual: Fly secrets + sync script → Cast portraits load; Reader Play after ElevenLabs secret.

Documentation and ADR impact

Update docs/OPERATIONS.md (public media + demo keys + ElevenLabs). Short ADR or amendment: character visuals may be public CDN URLs; Capture remains private. Living design: Mockups 2.0 Cast / Reader — behavior only, no mockup rewrite.

Risks and decisions

  • Locked: Character visuals (demo + apply) may be public; Capture attachments stay private.
  • Locked: Reader TTS stays server-only ElevenLabs (ADR 0009); quick link is ops guidance, not BYOK in browser.
  • Ops: Founder must set Fly secrets and run public-media sync once.
