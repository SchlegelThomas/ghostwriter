Ghostwriter delivery plan

Writing agent catalog

Status: active
Branch: feat/writing-agent-harness (continues harness PR until split)
Owner: founder + parent agent
Skill: ghostwriter-feature-delivery

Intent

Make Ghostwriter’s Agent dock a stage-organized catalog of real craft jobs — brainstorm → structure → writing → editing → commercialization — grounded in professional writing practice (multi-lens structure including Save the Cat, scene/sequel, character want/need; editorial ladder developmental → line → copy) rather than generic chat personas.

Agents detect/confirm book type (genre / story promise), give pacing and structural feedback with evidence, and help craft work — always propose-only. Structure/outline artifacts may land in Plans; other recommendations land in context on the entity they concern via entity drafts (accept / edit / reject lists attached to scene, cast, book, project — extending ADR 0011 proposals, not a second store).

Out of scope: autonomous multi-agent swarms; silent manuscript writes; marketplace skills; web research as authority; Playwright until founder verifies each major wave; inventing a parallel “drafts” table that bypasses proposal hash/apply.

Founder decisions (2026-08-01)

  1. Structure lenses: multi-lens from the start (Save the Cat beats + three-act / Hero’s Journey + scene/sequel + character want/need + genre conventions). Writer can set preferred lens; agents may recommend a lens but never lock the project to one.
  2. Stage names: keep Brainstorm / Structure / Writing / Editing / Commercial.
  3. Scope: deliver the full catalog (W0–W4) via feature-delivery vertical checkpoints — not a single bang.
  4. Landing: Plans for plan/outline-class artifacts; other outputs attach where they make sense. Prefer entity drafts (recs on the entity) over forcing everything through Capture/Inbox.

Domain / design audit

  • Today: dock modes chat / Plan / agent; five toolkit deep-links; durable proposals are Capture-bound (baseCaptureId required); craft targets live on receipt/payload; writing-assist is ephemeral (ADR 0009).
  • Entity drafts (accepted direction): extend ADR 0011 proposals with a primary target (capture | scene | story-knowledge | book | project), keep typed outputSchemaId + content-hash apply/reject/stale, index ready proposals on that target for entity UI. Capture remains optional context seed when useful; Plans stays the home for Capture-first idea work and plan-outline proposals.
  • Prose apply: still via named variants / editor insert / existing apply commands — drafts are recommendations, not a third prose store.
  • Living design: Mockups 4.0 (writing agents / craft) + 5.0 (BYOK / proposals / Inbox). Stage menu is additive chrome; entity draft rails are new UX on existing surfaces (Draft inspector, Cast dossier, Title Page, project).
  • Authority: ADR 0011 / 0013 — model never applies; exact hash + revision recheck. MCP ceiling remains read + propose.

Acceptance criteria (epic)

  • W0: Agent mode exposes stage menus; existing five jobs redistributed; context refusals unchanged; no new silent writes.
  • Foundation: Entity-draft binding + list UI on at least one entity (scene or project) with accept/edit/reject against ADR 0011 rules; ADR amended.
  • W1: Genre Compass + Story Architect + Pacing Doctor produce typed proposals with evidence; multi-lens selectable; genre card writer-overridable.
  • W2: Developmental Editor + Continuity Reader (findings invalidate without citations).
  • W3: Dialogue + Scene/Sequel coaches; Character Coach Cast-native entry.
  • W4: Pitch Pack + Query Coach + Series Bible; Cover remains Title Page.
  • Prior harness + dock QOL remain coherent; pnpm verify green; Playwright only after founder verifies each major wave outcome.

Tasks (vertical checkpoints)

  1. W0 — Stage menu chrome: Replace flat toolkit chips with Brainstorm / Structure / Writing / Editing / Commercial menus; map existing five agents; PRODUCT copy.
  2. F1 — Entity drafts foundation: Domain + storage + API to bind proposals to primary targets; list ready drafts on entity; accept/reject/edit-rebase; ADR 0011 amendment; thin UI on one surface (prefer scene inspector or project Title Page).
  3. W1a — Genre Compass: Infer + confirm genre/story-promise card on project; writable override; feeds later agents.
  4. W1b — Story Architect: Multi-lens beat board / outline → Plans or project draft; Save/acknowledge path.
  5. W1c — Pacing Doctor: Scene map vs lens % bands; findings with scene anchors on project/book drafts.
  6. W2a — Developmental Editor: Editorial-letter schema → project/book drafts.
  7. W2b — Continuity Reader: Evidence-linked findings on scene/project.
  8. W3 — Writing coaches: Dialogue + Scene/Sequel; Cast entry for Character Coach.
  9. W4 — Commercial pack: Pitch / Query / Series Bible; Cover unchanged home.
  10. Docs / handoff: PRODUCT, API, ADR; WHERE-I-LEFT-OFF per wave.

Tests and verification

  • API contract tests for new draft list/apply routes.
  • Browser walkthrough per checkpoint (success + refusal); record in record-log.
  • pnpm verify before each wave handoff. No Playwright until founder verifies.

Documentation and ADR impact

Update docs/PRODUCT.md (catalog + entity drafts). Update docs/API.md for draft list/bind routes. Amend ADR 0011 (or short ADR 0014) for primary-target proposals / entity drafts. Living design: Mockups 4.0, Mockups 5.0 — additive; surface conflicts rather than silent overwrite.

Risks and decisions

  • Accepted: Multi-lens; stage names; full W0–W4 via checkpoints; Plans for plan-class; entity drafts for contextual recs.
  • Accepted direction: Entity drafts = ADR 0011 proposals with primary target — not a second store. Capture-only invariant relaxes carefully with migration.
  • Risk: Scope — keep waves shippable; W0+F1 before smart agents.
  • Risk: Continuity without search/RAG — budgeted scene reads first; embeddings later if needed.
  • Accepted: First Drafts surfaces = scene inspector + project Title Page; Cast via story-knowledge inspector Drafts for Character Coach · Cast.
