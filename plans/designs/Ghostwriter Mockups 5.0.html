Quiet invitation · proposed

After acknowledged pause — never automatic egress.

When it appears

Only after capture is durably saved and the writer has been idle long enough to notice — not on first keystroke, not while Saving.

When it does not

Dismissal is durable enough not to nag. Dismissed captures never trigger network egress or consume provider budget by themselves.

Progressive setup · proposed

Write first. Configure collaboration when it becomes useful.

Profile and AI setup never block Capture. The first agent request opens one just-in-time path: connect a provider, review egress, then optionally describe how Ghostwriter should collaborate. Publishing identity and contact fields are never AI context by default.

1 · Immediate

Capture without setup

Sign in, open a project, and write. No genre quiz, craft form, provider key, or agent personality is required.

2 · First help request

Connect and consent

Add/test the OpenAI key, choose a model and budget posture, then inspect the context receipt before the first egress.

3 · Optional refinement

Writing preferences

Choose concise or exploratory collaboration, name content boundaries, and add project guidance. Skip or change it at any time.

Instruction boundary

Ghostwriter policy and workflow contracts remain non-overridable. Writer preferences, playbooks, manuscript text, uploads, and MCP content are untrusted inputs. Server policy—not prompt wording—enforces context scope, tool allowlists, egress, budgets, proposal-only authority, revision checks, and cross-project isolation.

Workflow walkthrough (static · no JS)
  1. Open Capture from Draft — write prose — Saved acknowledgement.
  2. Close Capture — return to Draft caret — open Inbox on another device — capture persists.
  3. Optional: deterministic promote to unassigned scene + Canvas card — same SceneId.
  4. After idle: quiet “Help find its place?” — dismiss or start Scene Partner.
  5. Review BYOK status and context receipt — confirm run — compare variants — apply one or dismiss.
  6. Optionally add project guidance or a declarative playbook — preview the effective instruction layers before use.
  7. Alternatively: craft partner typed deltas — apply selected fields only.
  8. External MCP submits proposal — appears in Inbox — human apply only.
